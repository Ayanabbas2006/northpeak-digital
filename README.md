# NorthPeak Digital 🚀

A modern, fully responsive one-page website built for a fictional digital agency, **NorthPeak Digital**. Developed with vanilla web technologies, featuring a clean aesthetic, accessible components, and robust client-side form validation.

🌐 **Live Demo:** [View Live Site](#) *(Replace with your Netlify/Vercel URL)*

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, and responsive media queries.
* **JavaScript (ES6+):** Mobile navigation toggle and advanced client-side form validation.

---

## 📋 Features & Requirements Met

* **a) Required Sections:**
  * **Hero Section:** Engaging headline, value proposition, call-to-action buttons, and floating stats/code snippet visual.
  * **Services Grid:** 6 distinct agency offerings with clean cards and hover micro-interactions.
  * **Results / Testimonials:** Proven client success stories with rating stars and attribution.
  * **Pricing Tiers:** 3 distinct pricing models (Starter, Growth, Enterprise) with a highlighted "Most Popular" card.
  * **Contact Form:** Fully functional client-side validation checking for empty fields, proper email formatting, and minimum message length.
* **b) Fully Responsive:** Tailored layout design intentionally optimized for mobile devices (**360px**), tablets (**768px**), and large desktop viewports (**1440px**).
* **c) Deployment & Version Control:** Clean codebase structured for instant deployment via Netlify, Vercel, or GitHub Pages.
